# 08 — Search (Поиск)

## URL: `/search?q=...`

## Назначение
Поиск товаров по названию, категории, особенностям.

## Компоненты

┌──────────────────────────────────────────┐

- Крестик для очистки
- Чипы популярных запросов (если поле пустое)

## Поисковый опыт
- Дебаунс: 300ms при вводе
- Минимум 2 символа для поиска
- Поиск по: названию, описанию, категории, тегам, product ID
- Результаты кешируются (5 минут)
- История поиска сохраняется локально (последние 10)

## i18n ключи
- `search.placeholder`, `search.noResults`
- `search.suggestions`, `search.categories`
- `search.popular`
