# UNIQLO KG — План клонирования сайта

## Цель
Создать идентичный (близнец) сайт uniqlo.com для франшизы UNIQLO в Кыргызстане.
Языки: Русский + Кыргызский (KG). Дизайн — точная копия оригинала, адаптированная
под локальный рынок.

## Стек

### Фронтенд
| Компонент | Выбор | Обоснование |
|-----------|-------|-------------|
| Framework | Next.js 16 + React 19 | RSC-first, SEO, опыт (bishway) |
| UI Kit | shadcn/ui (base-ui) | Минималистичный, нативный, чистый дизайн |
| Styling | Tailwind CSS v4 | Utility-first, строгая дизайн-система |
| i18n | next-intl | Сервер-сайд переводы, SSR-friendly |
| State | URL searchParams + nuqs | Корзина — localStorage + Zustand |
| Package | pnpm | Быстрее npm, строгие зависимости |

### Бэкенд (этап 2)
| Компонент | Выбор |
|-----------|-------|
| Database | PocketBase (SQLite, auth, file storage) |
| API | Next.js API Routes + PocketBase SDK |
| Admin | PocketBase Admin UI |

### Данные (этап 1 — моки)
- JSON файлы с товарами, категориями, медиа
- Структура данных — точная копия uniqlo.com/API

## Порядок реализации

### Фаза 1: Парсинг данных
1. Спарсить категории (Женщины, Мужчины, Дети, Младенцы)
2. Спарсить товары (~50-100 шт) с ценами, цветами, размерами, изображениями
3. Скачать изображения (референсы, не все)
4. Сформировать структурированные мок-данные

### Фаза 2: Фронтенд — скелет
1. Инициализация Next.js + shadcn/ui + i18n
2. Layout: Header (баннер, лого, nav, search, корзина)
3. Footer: Help, About, Group company
4. Навигация: табы WOMEN/MEN/KIDS/BABY + мегаменю

### Фаза 3: Страницы
1. Homepage — баннеры, категории, кампании
2. PLP — листинг товаров, фильтры, сортировка
3. PDP — галерея, селекторы цвета/размера, ATC
4. Cart — список, количества, рекомендации
5. Checkout — форма, доставка, оплата
6. Account — история заказов, профиль
7. Search — поиск по сайту

### Фаза 4: Бэкенд
1. PocketBase схема
2. Админка для товаров
3. API для корзины и заказов
