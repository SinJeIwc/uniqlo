# 01 — Homepage (Главная страница)

## URL: `/`

## Назначение
Точка входа. Промо-баннеры, навигация по категориям, кампании, новинки.

## Компоненты (сверху вниз)

### 1. Promo Banner (баннер над хедером)
```
┌─────────────────────────────────────────────────┐
│ 🔥 Save on Summer Essentials | Shop Now    [✕] │
└─────────────────────────────────────────────────┘
```
- Фиксированный сверху, даже над хедером
- Актуальная акция или промо
- Кнопка закрытия (крестик)
- Ссылка ведёт на кампанию или категорию

### 2. Header (см. 02-navigation.md)

### 3. Hero / Featured Banner

┌──────────────────────────────────────────┐

- Оверлей с текстом поверх фото

### 5. Campaign / Promo Cards (сетка)
Карточки в сетке 2-3 колонки, каждая — изображение + текст + CTA:

```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│  [IMAGE]     │ │  [IMAGE]     │ │  [VIDEO]     │
│              │ │              │ │              │
│ Now in New   │ │ Bra Tops     │ │ Shorts       │
│ Colors:      │ │ Built-in     │ │ Collection   │
│ Mini T-Shirt │ │ cups...      │ │ Must-haves   │
└──────────────┘ └──────────────┘ └──────────────┘
```

Типы карточек:
- **Продуктовые** — конкретный товар, цена, цвета
- **Коллекции** — категория товаров («Shorts Collection»)
- **Брендовые** — UNIQLO F.RISSO, коллаборации
- **Социальные** — партнёрства (The Trevor Project)
- **Видео** — автоплей видео с контентом
- **Маркетинговые** — розыгрыши, акции, GU

Всего ~12-15 карточек на главной.

### 6. Footer (см. 09-footer.md)

## Особенности
- Lazy loading изображений (blur-in анимация)
- Видео с автоплеем (muted, loop)
- Все ссылки — внутренние, не внешние
- Hover-эффекты на карточках: легкое затемнение + увеличение
- Мобильная адаптация: сетка 1 колонка, горизонтальный скролл

## Состояния
| Состояние | Описание |
|-----------|----------|
| Default | Загруженная страница |
| Loading | Skeleton-плейсхолдеры карточек |
| Error | Fallback с предложением обновить |
| Empty | Технически невозможно — всегда есть контент |

## i18n ключи
- `home.hero.title`, `home.hero.subtitle`, `home.hero.price`
- `home.categories.title`, `home.categories.seeAll`
- `home.campaigns.*` — для каждой кампании
- `home.footer.*` — повторяет ключи футера
