# 02 — Navigation (Навигация и мегаменю)

## URL: присутствует на всех страницах

## Компоненты

### 1. Promo Banner
- Над хедером, фиксированный
- Текст акции + ссылка + кнопка закрытия
- При закрытии — сохраняется в sessionStorage, не показывается до перезагрузки

### 2. Header Bar
```
┌──────────────────────────────────────────────────────────┐
│ [LOGO]  WOMEN | MEN | KIDS | BABY    🔍  ♡  👤  🛒  ☰ │
└──────────────────────────────────────────────────────────┘
```

#### Логотип
- Красный квадрат с белым шрифтом UNIQLO
- Ссылка на `/`

#### Main Tabs: WOMEN | MEN | KIDS | BABY
- Горизонтальный tablist
- Активный таб — подчёркнут (жирный шрифт)
- При наведении — дропдаун с мегаменю

#### Иконки (справа)
| Иконка | Действие | Ссылка |
|--------|----------|--------|
| 🔍 Поиск | Открывает поисковую панель | `/search` |
| ♡ Избранное | Список желаемого | `/wishlist` |
| 👤 Аккаунт | Личный кабинет | `/account` |
| 🛒 Корзина | Корзина (с бейджем количества) | `/cart` |
| ☰ Меню | Гамбургер (мобильное меню) | — |

```
┌─────────────────────────────────────────────────────────┐

│  T-Shirts & Sweats     Outerwear       Featured         │

│  Shirts & Blouses      Innerwear         Sale           │
│  Sweaters & Cardigans  Accessories       Limited-Time   │
│  Bottoms               Linen             GU             │
│  Shorts & Culottes     AIRism                           │
│  Jeans                 UNIQLO F.RISSO                   │
│                                                         │
│  [IMAGE: текущая кампания]                              │
└─────────────────────────────────────────────────────────┘
```

Структура мегаменю:
- **Левая часть (70%)** — список категорий, сгруппированных в 3 колонки
- **Правая часть (30%)** — промо-изображение с ссылкой на кампанию
- Фон: белый, тень
- Анимация: fade-in + slide-down (200ms)

### 5. Search Panel
```
┌──────────────────────────────────────────┐
│ 🔍 What are you looking for?             │
│                                          │
│ Popular searches:                        │
│ • AIRism • Linen • T-Shirt • Bra Top    │
│                                          │
│ [Live results as you type]              │
└──────────────────────────────────────────┘
```
- Оверлей поверх страницы
- Инпут с автофокусом
- Популярные запросы (если пусто)
- Live-поиск с дебаунсом 300ms
- Результаты: товары (изображение + название + цена)
- Закрытие: Escape, клик вне панели

## Состояния
| Компонент | Состояния |
|-----------|----------|
| Promo Banner | visible / dismissed |
| Header | default / scrolled (тень, компактный) |
| Mega Menu | closed / open (hover) |
| Cart Icon | empty / has-items (бейдж) |
| Search | closed / open / results / no-results |
| Mobile Menu | closed / open / submenu-open |

## Поведение при скролле
- Промо-баннер: скрывается при скролле вниз
- Хедер: фиксированный, при скролле добавляется `box-shadow`
- На десктопе: при скролле вверх — появляется (sticky)
- На мобильном: постоянно видимый

## i18n ключи
- `nav.women`, `nav.men`, `nav.kids`, `nav.baby`
- `nav.search`, `nav.wishlist`, `nav.account`, `nav.cart`
- `nav.categories.*` — все категории
- `nav.mobile.*` — мобильное меню
