# Скрипты — конвенции

## Структура

```
scripts/
  categories/            # Всё про категории
    parse.py             #   Парсер (можно несколько файлов если сложно)
    categories.md        #   Инструкция (CLI, параметры, формат)
    women.md             #   Данные: имена категорий
    men.md
    kids.md
    baby.md
  homepage/              # Всё про главную
    parse_homepage.py    #   Парсер (один файл — норм)
    homepage.md          #   Инструкция (CLI, параметры, формат)
```

## Правила

1. **Одна папка — одна доменная область.**
2. **Парсер = 1+ файлов.** Если нужно — декомпозируй. Нет жёсткого правила "один файл".
3. **`*.md` рядом с парсером** — документация: что делает, CLI-параметры, формат данных.
4. **md-файлы данных** — чистые, без дубликатов, с заголовком `# Gender — описание`.
5. **Запуск из корня `scripts/`:** `uv run python categories/parse.py`.
6. **Пути в коде — относительно `__file__`.**
